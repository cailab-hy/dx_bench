# DX 침실 벤치마크(dx_bed_v0) 진행 보고

2026-10-16 ~ 10-20 · RB-Y1 · Isaac Sim 6.1 / Isaac Lab 3.0 / IsaacLab-Arena 0.3.1 (PhysX)

## 1. 목표

DX허브 11층 케어룸 디지털 트윈에서 Rainbow Robotics RB-Y1으로 VLA·모방학습 정책을 평가하는 벤치마크를 만든다.

과제는 세 가지다.
- BED-01 침대 정리
- BED-02 옷 개기
- BED-03 빨래 바구니에 옷 넣기

## 2. 만든 것

| 단계 | 내용 | 결과 |
|---|---|---|
| 1 천 시뮬 | 표면 변형체 천 + 보조 잡기(닫으면 손끝 근처 천 정점을 손에 고정) | 이불·소매·바닥 옷 잡기 오차 ≤ 1.3 cm, 60 s 안정. 마찰 잡기는 실패 |
| 2 로봇 | `rby1_joint`(24-D 관절), `rby1_ik`(17-D 손끝 IK + 몸통 자세 + 베이스 속도) | 회귀 테스트 6종 통과 |
| 3 과제 | 3과제 × 3난이도 평가 장면 90개, 학습 장면, 판정 규칙(pytest), 천 초기 상태 | BED-03 Easy oracle **8/10** |
| 4 데이터 | 키보드·VR 원격조작, 원본 기록기, LeRobot v3 변환(dx24 / 실기 16-D) | 변환 비트 단위 일치, 재생 시 과제 성공 재현 |

| 6 벤치마크 | 실험 YAML 하나로 평가 → 실험별 보고서 + 전체 결과표 | `benchmarks/dx_bed_v0/RESULTS.md` |

## 4. 학습 정책 실험 (BED-03 Easy)

**데이터**
- oracle 데모 **92개**(100장면 중), 132,980프레임, 에피소드당 약 96 s.
- 바뀌는 조건: 바구니·옷 위치, 옷 방향, 구김.
- 고정된 조건: 옷 종류(파란 티셔츠 + 큰 수건), 로봇 시작 위치, 조명, 지시 문장.

**학습**

| 모델 | 설정 | 최종 loss |
|---|---|---|
| ACT | 100k step | 0.037 |
| SmolVLA | `smolvla_base` 미세조정, 20k step | 0.030 |

**평가 결과** (최대 120 s, 10장면)

| 정책 | 평가 장면(처음 보는 옷) | 학습 장면(본 옷) |
|---|---|---|
| oracle (정답 스크립트) | 8/10 | — |
| 아무것도 안 함 / 데모 1개 재생 | 0/10 / 0/10 | — |
| ACT (데모 24개, 이전 조건) | 0/10 | — |
| **ACT (데모 92개)** | **0/10** | 0/3 |
| **SmolVLA (데모 92개)** | **0/10** | 0/3 |

**진단** (학습 프레임에서 첫 행동의 평균 오차, 낮을수록 좋음)

| | ACT 92 | SmolVLA 92 | 지금 상태 유지 | ACT 24 |
|---|---|---|---|---|
| 팔 (rad) | 0.0045 | 0.0049 | 0.0103 | 0.0101 |
| 베이스 속도 | 0.026 | 0.036 | **0.017** | 0.043 |

- **팔:** 데모를 늘린 효과로 2배 이상 정확해졌다.
- **베이스:** 상태 유지보다도 나쁘다. 과제 시간의 대부분인 4–5 m 주행을 배우지 못해 옷 앞에 서지 못한다.
- **원인 범위:** 학습 장면에서도 0/3이므로 옷이 달라서만 생긴 실패가 아니다.

## 5. 남은 과제와 제안

1. **이동과 조작 분리:** 옷 앞에서 시작하는 단거리 과제로 집기·넣기를 먼저 학습·평가한다. 주행은 따로 다룬다.
2. **데모 품질·다양성:**
   - oracle 베이스 명령을 부드럽게 한다.
   - 장면 생성기 셔츠 선택 버그를 고친다.
   - 시작 위치·조명·문장을 무작위로 한다.
   - 회복 동작을 넣는다.
3. **사람 데모:** BED-01·BED-02는 VR 원격조작 데모로 채운다. VR 헤드셋 실착용 시험이 필요하다.
4. **사람이 결정할 것:**
   - 보조 잡기와 실기의 차이를 어디까지 줄일지
   - π0 가중치(5 GB 초과) 다운로드
   - 대규모 학습 자원
