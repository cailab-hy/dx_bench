# 구김 모양 (2026-10-23, D-46)

사용자: "실물 옷·수건·이불 영상을 보면 지금처럼 심하게 구겨지지 않는다. 유튜브 영상도 같이 보고 실제와 비슷하게."

그림: `compare.jpg`. 위: 실물(유튜브: SpeedFolding 반팔티, Berkeley PR2 수건, 한국식 이불 정리). 가운데: 이전. 아래: 수정 후.
왼쪽부터 반팔티, 수건, 이불.

## 원인 두 가지
1. **굽힘이 꺼져 있었다.** PhysX 표면 천의 `omniphysics:surfaceBendStiffness`가 0이면 굽힘 제약 자체를 건너뛴다
   (PhysX 소스 `PxgFEMCloth.cpp`: kInv = −1. 영률로 계산하는 식은 `#if 0`으로 꺼져 있음). 스키마 설명("기본은 영률·두께에서
   계산")과 실제 코드가 다르다. 그래서 천은 굽힘 에너지가 0이고, 선형 삼각형의 막 잠김만으로 정적 처짐이 그럴듯해 보였을 뿐
   구기면 모든 모서리(2 cm 격자)에서 꺾였다. 확인: 상자 끝에 8 cm 내민 수건의 처짐이 영률 1e4–1e6, 두께 1.5–6 mm에 상관없이
   같았다(84°, 굽힘 길이 1.7 cm). `surfaceStretchStiffness`·`surfaceShearStiffness`는 PhysX가 읽지 않는다("not supported").
2. **렌더가 삼각형마다 평평하게 칠했다.** 두께 껍질 메시가 `subdivisionScheme = none`이고 법선이 없어, 2 cm 삼각형이
   각진 면으로 보였다(구겨진 종이). `catmullClark`(세분 0단계)로 바꾸면 RTX가 매 프레임 부드러운 법선으로 칠한다.
   `loop`는 깨지고, 세분 단계 > 0은 GPU 스키닝이 위치를 갱신하지 못한다.

## 굽힘 값 (Pa, 힌지 강성 = 값 × 두께³)
Peirce 처짐 시험(상자 끝 8–12 cm 내밀기)으로 잰 굽힘 길이 c = (D / 무게)^(1/3):

| 값 | 수건(1.5 mm) | 이불(2 mm) |
|---|---|---|
| 0 (이전) | 1.7 cm (격자 한계) | – |
| 1e4 | 2.3 | – |
| 3e4 | 2.8 | – |
| 1e5 | 3.8 | 5.0 |
| 3e5 | – | 6.9 |
| 1e6 | 7.3 | – |

실물 문헌값: 면 저지 KES B 0.007–0.05 gf·cm²/cm(D ≈ 0.7–5e-6 N·m), 테리 수건 ≈ 1–4e-6 N·m, 누빔 이불
(1.3 cm 솜) 2.9–4.4e-4 N·m. 반팔티·수건의 실제 굽힘 길이(약 1 cm)는 1.7–2.3 cm 격자보다 작아 그대로 넣으면 다시
모서리마다 꺾인다. 그래서 둥근 주름으로 구겨지는 가장 무른 값을 골랐다.

| 천 | 값 | 굽힘 길이 | 구김 시험: 60° 넘게 꺾인 모서리 비율 (이전 → 이후) |
|---|---|---|---|
| 반팔티 | 5e3 | 약 1.7 cm | 13.8 % → 3.9 % |
| 수건 | 2e4 | 약 2.5 cm | 18.4 % → 4.7 % |
| 이불 | 5e4 | 약 3.7 cm (D ≈ 2e-4 N·m, 누빔 이불 범위) | 14.3 % → 1.0 % |

## 다른 시험에 미친 영향
- 수건 접기 유지(`towel_fold.py`, 짧은 변 접기): 굽힘 0 / 3e4 / 5e4 / 1e5 모두 접힘 유지. 잡고 옮길 때 최대 변형률 73 % → 4–5 %
  (굽힘이 없으면 국부적으로 심하게 구겨졌다).
- 반팔티(`tee_match.py`): 접은 쪽 유지 100 %(5e3: 99.8 %), 매달린 길이 0.60 m 그대로, 한 모서리 들기에서 책상에 남는 비율
  0.57 → 0.44(굽힘으로 더 많이 따라 올라옴).
- 이불 침대 처짐(`duvet_match.py`): 모서리 퍼짐 9 → 21 cm. 실물 사진(`bed.mp4` 끝)의 발치 모서리도 판처럼 접히지 않고
  밖으로 퍼진다. 굽힘 0일 때는 모서리가 날카롭게 꺾여 붙었다.
- 굽힘이 들어가면 초기 상태(구긴 더미·접은 이불)가 달라지므로 평가 상태 100개 재생성.
