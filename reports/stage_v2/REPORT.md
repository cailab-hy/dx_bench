# v2 데모·학습·평가 (D-U10 / D-31, 2026-10-19–20)

새 조건(보조 잡기 반경 2.5 cm, 수건 영률 1e5)의 BED-03 Easy oracle 데모로 ACT와 SmolVLA를 동시에 학습하고 평가했다.

## 데이터

| 항목 | 값 |
|---|---|
| 수집 | `Bed03OraclePolicy`(특권 정보) + `rby1_ik`, 학습 장면 100개(seed 10000–10099), 5개 동시, 성공만 저장 |
| 결과 | **92/100 성공**(실패 8, GPU 오류 0, 제외 0). 10-19 오전 정전 뒤 무결성 검사(92개 모두 정상) 후 재개 |
| 변환 | `data/lerobot/bed03_oracle_v2_dx24`: 92 에피소드, 132,980프레임(1,313–1,617프레임, 평균 96 s), 검증 통과 |
| 다양성 | 바뀜: 바구니·옷 위치(방 전체), 옷 방향, 옷 초기 구김, 로봇 시작 방향. 고정: 옷 종류(**모두 파란 티셔츠 + 큰 수건** — 장면 생성기가 Easy에서 첫 번째 셔츠만 고름), 로봇 시작 위치, 지시 문장 1개, 조명. 행동 전략 1가지(오른팔만, 다시 잡기 92개 중 1회) |

| | ACT | SmolVLA |

## 평가 (상한 1800 step = 120 s)

| 실험 | 장면 | 성공 | 비고 |
|---|---|---|---|
| `act_bed03_v2` | 평가 10(처음 보는 옷) | **0/10** | 오류 0, 바구니를 넘어뜨려 2회 일찍 종료 |
| `smolvla_bed03` | 평가 10 | **0/10** | 오류 0 |
| `act_bed03_v2_train` | **학습 장면 3**(본 옷) | 0/3 | 진단 |
| `smolvla_bed03_train` | 학습 장면 3 | 0/3 | 진단 |

- 행동: 두 정책 모두 데모의 동작 형태(주행, 몸통 숙이기, 팔 내리기)는 따라 하지만, 옷 앞에 정확히 서서 집지 못한다.
  - ACT는 4.7–6.4 m를 다니며 바구니·옷 0.2–0.8 m까지 접근.
  - SmolVLA는 옷 0.06 m까지 간 장면도 있으나 소파 쪽에서 멈추기도 함.
  - 머리 카메라 장면: `act_v2_eval001_head.png`, `smolvla_eval001_head.png`(300 step 간격).
- **학습 장면에서도 0/3** → 평가 옷이 달라서(OOD)만이 아니라, 데모 분포 안에서도 과제를 해내지 못한다.

## 진단: 학습 프레임 개루프 오차 (첫 행동, 60프레임, `*_openloop_train.json`)

| 행동 묶음 | ACT v2 | SmolVLA | "상태 유지" 기준 | v1 ACT(24 데모) |
|---|---|---|---|---|
| 팔 (rad) | 0.0045 | 0.0049 | 0.0103 | 0.0101 |
| 몸통 (rad) | 0.0028 | 0.0047 | 0.0120 | 0.0093 |
| 그리퍼 | 0.0 | 0.0 | 0.0101 | 0.0 |
| **베이스 (m/s, rad/s)** | **0.0258** | **0.0357** | **0.0166** | 0.0434 |

- 팔·몸통은 기준보다 2–4배 정확하다. v1은 기준과 같은 수준이었으니 데모를 늘린 효과가 있다.
- **베이스 속도만 기준보다 나쁘다.** 과제 시간의 대부분은 4–5 m 주행인데, 정책이 이 이동을 배우지 못했다.
  - oracle의 베이스 명령은 A* 경로 추종에 "제자리 회전 / 직진" 전환이 섞인 형태라 영상만으로 예측하기 어렵다.
  - 옷이 멀면 머리 카메라에 잘 안 보인다.

## 다음에 해 볼 것 (제안)

1. **이동과 조작 분리:** 옷 앞에서 시작하는 단거리 변형(예: BED-03 "pick-place from near")으로 조작을 먼저 학습·평가한다. 주행은 별도 정책이나 고전 내비게이션으로 처리한다.
2. **베이스 행동 다듬기:** oracle의 베이스 명령을 부드럽게 만들고(전환 대신 연속 속도), 정책 입력에 베이스 속도 이력을 더한다.
3. **다양성:**
   - 장면 생성기 셔츠 선택 버그를 고친다(m_blue / s_red 섞기).
   - 로봇 시작 위치·조명·지시 문장을 무작위로 한다.
   - oracle에 잡음을 넣어 회복 동작을 담는다(DART).
4. **데이터 양:** 장면당 데모를 여러 개 모으고, 사람 VR 데모를 섞는다.
